# 综合行政管理系统：工作台

本说明覆盖当前用户的“我的待办”“我的已办”及其签收、归还动作。调用前读取 [`../auth.md`](../auth.md) 并验证当前用户。

> 固定工作台端点与字段 schema 未在可恢复上下文中保留。不得根据日报接口、页面路由或常见框架路径猜测。首次使用每个功能时，从浏览器读取对应页面加载的真实 XHR/fetch，再将已验证的读取请求交由 HTTP 客户端复用。

## 查询我的待办/已办

1. 打开目标列表页面，仅允许页面读取与 `GET`/其他已确认只读请求。
2. 捕获实际列表请求的 URL、方法、分页参数、可选筛选参数、响应中总数及任务唯一标识；敏感字段脱敏。
3. 允许按页面实际提供的流水号、工作名称/文号、流程定义等字段筛选；未在真实请求中出现的字段不得传递。
4. 返回筛选条件、总数、任务标识、工作名称、流程状态、办理人和必要时间；不回显令牌、Cookie 或审批链接敏感参数。

## 签收与归还

签收、归还都会改变流程任务归属或状态，属于业务写操作。

1. 先用实时待办列表定位唯一任务，读取其任务 ID、当前状态、是否允许签收/归还和页面显示的办理人。
2. 从真实页面请求获得该动作的 URL、HTTP 方法、请求 body/schema 和必要前置条件；探索时不能点击或发送写请求。
3. 展示完整待提交请求数据、目标任务、动作前状态、预期动作后状态和影响范围。
4. 仅在用户针对该完整数据明确确认后发送一次请求。
5. 重新查询待办/已办，确认任务状态、归属和列表位置符合预期。写入失败或令牌失效时不自动重试。

## 流程安全

- 只对唯一定位的任务执行动作；筛选出现多条记录时要求用户选择目标，不凭标题猜测。
- 已办任务通常不允许签收或归还；以实时页面状态和真实响应为准。
- 不执行审批、撤回、转办、加签、删除或其他未在本说明中确认的动作。用户提出这些意图时，按 [`../auth.md`](../auth.md) 的动态业务发现流程先读取真实页面和只读 schema。
